How to use it

  1. Drag the button above onto your browser's bookmarks bar.
  2. Open any Amazon product page you want to add.
  3. Click the bookmark. It grabs the ASIN, title, price, image and brand and adds them to a running list.
  4. Repeat for as many products as you like.
  5. Click ⬇ Download CSV in the toast.
  6. On GitHub, put that file in imports/ via Add file → Upload files and commit. A workflow imports it and opens a pull request for you to review.
Use Download, not copy-paste, for more than one product. The Actions "paste CSV" box is a single-line field, so a multi-row CSV pasted there loses everything after the first line. The downloaded file has no such limit. If you do want to paste, base64 it first (base64 -w0 products.csv) — the workflow detects and decodes that.

Prefer a terminal? The same file works locally:

node scripts/ingest.mjs --import products-12.csv
node scripts/ingest.mjs --review
node scripts/ingest.mjs --commit --approve-all
npm run build
This is not a scraper. It doesn't crawl, fetch, or automate anything. It reads the page you deliberately opened, in your own browser, and writes text to your clipboard — nothing leaves your machine and no page is visited that you didn't visit yourself. Bulk automated collection would breach the Associates agreement and put the affiliate account at risk; this doesn't.

Good to know

  • Amazon's markup varies by category, so if a field can't be read the toast says which one. Fill that cell in by hand before importing rather than trusting a blank.
  • Clicking the same product twice won't duplicate it.
  • The list persists in localStorage on amazon.com, so you can collect across several sessions. Clear list in the toast resets it.
  • If the clipboard is blocked by permissions policy, the toast shows a text box to copy from manually.
  • Not sure what to shop for? Run node scripts/gap-report.mjs — it names the facets currently blocking pages, and flags that higher-priced stock is the top priority.
